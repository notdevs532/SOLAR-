# SOLA - A solar system 3-D website

## This is a Website on solar system 
A 3-d model website on solar system. </br>
It contains all the information of all planets in solar system, have a zoom in and zoom out feature,rotation and revolution plants. </br>
It is made by using Java script, THREE js , CSS, HTML.</br>
Fully  controlled by mouse can zoom in or zoom out, left or right.

## Why I made this
I want to explore THREE.js  and want to create a 3-D model of solar system which store every and each planet information. </br>
Want to create an interesting experience to explore plants and easy to take information. </br>

## Process of making it
Firstly, I store information of planets in java script and create a basic HTML and CSS. </br>
Then create sphere by using THREE.js and applied textures to the planets using images,  do it same for sun  also. </br>
Put rotation and revolution, zoom in and out animation, and then clickable animation to zoom on a particular planet.  </br>

##  bugs/setback along the way
My brain got cooked by the bugs while making the this website like a changed a digit and randomly stars become too big and camera shifted too left </br>
Black screen was a major issue to deal with. </br>
The showing of information and animation also got lots of bugs.
