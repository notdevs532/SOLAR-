# This is a Website on solar system 
A 3-d model website on solar system.
It contains all the information of all planets in solar system, have a zoom in and zoom out feature,rotation and revolution plants.
It is made by using Java script, THREE js , CSS, HTML.
Fully  controlled by mouse can zoom in or zoom out, left or right
